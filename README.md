# partyatredrocks

## Data Truth

- Canonical venue registry bridge: `data/venues.registry.json`
- Canonical show ledgers: `data/shows/<venue-key>/2026.json`
- Ledger row contract:
  - `dateKey` (`YYYY-MM-DD`)
  - `title` (headliner/title string)
  - `support` (optional comma-separated support string)
- Compiled snapshots: `data/snapshots/**` (generated by `npm run build-events`)
- Registry bridge rule: registry `key` maps ledger directory and snapshot filename stem; registry `slug` maps venue pages/routes.

## Constitution

- Truth layer: `data/shows/<venue-key>/<year>.json`
- Compiled layer: `data/snapshots/**`
- UI layer: pages/components read snapshots only
- Enrichment layer: provider APIs / Blob may decorate data, never gate build or SSG
